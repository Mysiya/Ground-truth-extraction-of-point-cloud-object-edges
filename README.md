# 点云边缘真值提取平台

**Ground Truth Edge Extraction Platform for Point Cloud Objects**

从 OBJ 三维网格模型中自动提取几何尖锐边缘作为真值。基于**二面角方法**：计算相邻三角面之间的二面角，超过阈值的边即判定为尖锐边缘；同时将网格边界边也标记为边缘。

---

## 功能特性

- 📤 **上传 OBJ 文件** — 支持拖拽或点击上传 Wavefront OBJ 格式的三维网格模型
- 🎛️ **可调参数** — 二面角阈值、采样密度、最小采样点数均可调节
- ⚡ **实时提取** — 基于二面角的尖锐边缘提取算法，纯 Python 标准库实现
- 👁️ **3D 可视化** — 基于 Three.js 的交互式三维查看器，支持旋转/缩放/平移
  - 半透明网格表面 + 线框
  - 红色高亮尖锐边缘线段
  - 黄色边缘采样点
  - 图层独立开关
- 📥 **结果下载** — 一键下载边缘点云（PLY 格式）和边缘线段列表（TXT 格式）

## 使用说明

### 1. 上传文件
将 `.obj` 三维网格文件拖拽到上传区域，或点击选择文件。支持任意大小的 OBJ 文件（最大 200MB）。

### 2. 调整参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 二面角阈值 | 25.0° | 相邻面夹角超过此值判定为尖锐边缘。值越小，提取的边缘越多 |
| 采样密度 | 50.0 点/单位 | 每单位长度采样的点数，影响边缘点云的密度 |
| 最小采样点 | 2 | 每条边最少的采样点数，避免极短边无采样点 |

### 3. 提取边缘
点击"提取边缘"按钮，系统会自动：
1. 解析 OBJ 网格
2. 计算所有面的法向量
3. 检测二面角超过阈值的尖锐边
4. 沿每条尖锐边均匀采样
5. 生成结果文件并在 3D 视图中展示

### 4. 查看结果
- **鼠标左键拖拽**：旋转视角
- **鼠标滚轮**：缩放
- **鼠标右键拖拽**：平移
- **按 R 键**：重置视角
- 使用顶部工具栏切换图层显示

### 5. 下载结果
- **边缘点云 (.ply)**：标准 PLY ASCII 格式，包含所有边缘采样点的三维坐标
- **边缘线段 (.txt)**：每行一条边缘线段，格式为 `edge_id x1 y1 z1 x2 y2 z2`

## 算法原理

### 二面角边缘检测

1. **解析 OBJ** — 读取顶点坐标和面索引，对多边形面进行扇形三角剖分
2. **构建边-面映射** — 建立每条边到其邻接面的索引映射
3. **计算面法向量** — 对每个三角面计算单位法向量
4. **边缘判定**：
   - **边界边**（仅有一个邻接面）→ 始终标记为边缘
   - **内部边**（有两个及以上邻接面）→ 计算各邻接面法向量之间的夹角，若**任意一对**夹角 ≥ 阈值，则标记为尖锐边缘
5. **采样** — 沿每条边缘线段均匀插值采样点

```
二面角 = arccos(n1 · n2)
其中 n1, n2 为相邻面的单位法向量

如果 二面角 ≥ 阈值 → 尖锐边缘
如果 边只有一个邻接面 → 边界边缘
```

## 常见问题

**Q: 上传后没有显示任何边缘？**
A: 尝试降低二面角阈值（如设为 10°），或检查 OBJ 文件是否包含足够的几何细节。

**Q: 3D 视图性能较差？**
A: 大型模型（>50万面）可能导致渲染性能下降。可尝试降低采样密度减少边缘点数量。

**Q: 支持哪些 OBJ 格式？**
A: 支持标准的顶点（`v`）和面（`f`）定义，包括带纹理坐标和法向量的面索引。四边形及以上多边形会自动三角剖分。
